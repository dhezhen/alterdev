# Audit Panel Admin

Audit ini meninjau halaman admin yang sedang terbuka, dasbor, navigasi, dan pengalaman saat data kosong. Belum ada perubahan pada UI.

## Temuan

1. **[HIGH] Empty state belum memberi langkah berikutnya.** *(R-27)*
   Dasbor hanya menampilkan pesan seperti “Belum ada pesan masuk” dan “Belum ada jadwal mendatang”. Tambahkan tindakan yang relevan, misalnya tombol untuk membuka formulir atau panduan menambahkan data pertama. Acuan: `resources/views/admin/dashboard.blade.php:43-77`.

2. **[LOW] Prioritas dasbor belum mengikuti fokus layanan Alterdev.** *(R-20)*
   Enam kartu statistik, dua daftar pelatihan, grafik pesan, dan tombol utama “Jadwal Pelatihan” mendapat bobot serupa. Dahulukan pesan calon klien dan pengelolaan website, sistem informasi, serta aplikasi; letakkan kegiatan pelatihan sebagai prioritas sekunder. Acuan: `resources/views/admin/dashboard.blade.php:11-24` dan `48-83`.

3. **[LOW] Ringkasan testimoni terlalu pendek untuk ditinjau dari daftar.** *(R-20)*
   Isi ulasan dipotong pada 120 karakter, sehingga admin harus membuka halaman edit hanya untuk membaca konteks lengkap. Tambahkan pratinjau yang bisa dibuka atau panel detail tanpa meninggalkan daftar. Acuan: `resources/views/admin/testimonials/index.blade.php:15-24`.

4. **[LOW] Navigasi samping panjang pada layar kecil.** *(R-20)*
   Semua tautan menu tampil sekaligus, sehingga admin perlu menggulir daftar panjang di panel samping. Buat kelompok menu dapat dilipat dan buka otomatis kelompok yang memuat halaman aktif. Acuan: `resources/views/admin/layout.blade.php:9-26`.
